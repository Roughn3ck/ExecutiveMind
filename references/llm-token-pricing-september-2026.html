Reading the Numbers

  • Cheapest real reasoning per token: DeepSeek V4-Flash ($0.14/$0.28) and GPT-6 Luna ($0.10/$0.50) — frontier-family reasoning at flash pricing.
  • Batch APIs: −50% on OpenAI, Anthropic, and Google; −40% on Moonshot (excluding K3). Caching: −90% on input (Anthropic), ~99.9% on cache hits (DeepSeek), $0.03 (GLM Flash), $0.30 (Kimi K3).
  • Watch: Gemini bills thinking tokens at output rates; DeepSeek official docs now show a peak/off-peak split (peak = 2×).
  • OpenRouter is a router, not a model: per-token price = underlying provider rate + fee. Value = failover + one API key.
  • Verify before contracting. Prices as published late September 2026. Provider pricing pages move; the PDF is a snapshot, not a contract.
